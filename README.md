# Kolkata Floodplain Atlas

Interactive atlas of urban growth and flood risk on the Kolkata-Howrah-Hooghly floodplain, 2017-2025.

Team: Abhay Chauhan (25113004), Abhinav Parashar (25113007), Anahad Rakhra (25113018), Durgesh Kushwaha (25113046).
Supervisor: Prof. Siddhartha Khare, Department of Civil Engineering, IIT Roorkee.

Static site: open `index.html` through any web host (GitHub Pages, Netlify). The map layers are in `layers/`.
Leaflet 1.9.4 (BSD-2-Clause) is loaded from cdnjs; its stylesheet is inlined.
